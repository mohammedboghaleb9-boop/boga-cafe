# BOGA CAFÉ

الموقع الرسمي لـ **BOGA CAFÉ** (تحميص وبيع · وجدة، المغرب): متجر قهوة حبوب، خلطة خاصة (Custom Blend) مرتبطة بالمخزون، قسم للمهنيين B2B / HORECA، ولوحة إدارة كاملة. بثلاث لغات: العربية والفرنسية والإنجليزية.

> **الحالة:** المرحلة 1 مكتملة: نموذج كامل يعمل ببيانات تجريبية. المتبقي هو الربط بالخدمات الخارجية (قاعدة البيانات على الإنترنت، بوابة الدفع CMI، واتساب، Gmail). التفاصيل في [`docs/`](docs/README.md).

## ما يحتويه النموذج

**المتجر:** الرئيسية · المتجر · صفحة المنتج · أحادي المصدر · الخلطة الخاصة (الأنواع، النسب = 100%، الوزن، سعر مباشر، فحص المخزون لكل مصدر) · B2B (3 خلطات، طلب عيّنة 500 غ) · السلة (قاعدة 10 كلغ) · الدفع في صفحة واحدة بدون حساب (بطاقة / كاش بلوس / تحويل، بدون دفع عند الاستلام) · صفحة الطلب · اتصل بنا.

**الإدارة (`/admin`، كلمة المرور التجريبية `boga2026`):** لوحة القيادة · الطلبات · المهنيون والعيّنات · المنتجات والخلطات · المخزون والمصادر · التوصيل · المدفوعات · الإشعارات · المحتوى · الإعدادات. ثلاثة أدوار: مالك، مسيّر، موظف.

## جرّب هذه السيناريوهات

1. **الخلطة الخاصة:** غيّر النسب، لاحظ السعر والغرامات، جرّب مجموعاً ≠ 100%، لاحظ أن «إثيوبيا» غير متاحة مع تاريخ العودة.
2. **طلب كامل:** أضف منتجاً ← السلة ← الدفع (رقم مثل `0612345678`) ← ادفع بالبطاقة (محاكاة).
3. **الإدارة:** افتح «الطلبات» وسترى طلبك، والغرامات لكل مصدر، والمخزون المحجوز. غيّر حالته، ألغِه، وشاهد المخزون يعود في «المخزون والمصادر».
4. **الإشعارات:** «الإشعارات» تعرض رسالة واتساب والبريد التي وصلت للإدارة عن طلبك.
5. **قاعدة 10 كلغ:** أضف 11 كيس 1 كلغ ← السلة تمنع الدفع وتقترح واتساب أو إرسال طلب B2B.
6. **العيّنة:** من صفحة B2B أرسل طلب عيّنة ← تظهر في «المهنيون والعيّنات» مع قرار «مجانية / على حساب الزبون».
7. **الأدوار:** اخرج وادخل بدور «موظف»: لا يرى المدفوعات ولا الإعدادات، ولا يغيّر الأسعار.
8. **اللغات:** بدّل إلى العربية: الاتجاه من اليمين لليسار في كل الصفحات والإدارة.

## التشغيل

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 19 اختباراً لمنطق الأعمال
npm run typecheck
npm run build        # نسخة الإنتاج
npm run build:demo   # النموذج في ملف HTML واحد: dist-demo/index.html
```

## التقنيات

React 19 · TypeScript · Vite · React Router · CSS بمتغيرات وخصائص منطقية (RTL) · Vitest · Supabase (PostgreSQL + RLS + Auth + Edge Functions) للإنتاج. السبب والتفاصيل: [`docs/03-architecture.md`](docs/03-architecture.md).

## تنظيم المشروع

```
src/core       منطق الأعمال (الأسعار، الخلطة، المخزون، التوصيل، الطلب) + الاختبارات
src/data       البيانات: التجريبية الآن، Supabase في المرحلة 2
src/services   الدفع والإشعارات كمحوّلات قابلة للاستبدال
src/i18n       العربية / الفرنسية / الإنجليزية
src/features   الأقسام، كل قسم في مجلده (home, shop, custom-blend, b2b, cart, checkout, admin/…)
src/shared     المكونات المشتركة (الكيس السداسي، الأعلام، الرأس، التذييل)
supabase       مخطط قاعدة البيانات للإنتاج + اختباره
docs           التحليل، الدراسة، البنية، الخدمات، خطوات البناء، دليل الأقسام، الأسئلة
```
