# 08 · الصور والهوية البصرية المعتمدة

> هذه الوثيقة هي المرجع الوحيد لأي صورة أو شعار يدخل الموقع أو الطباعة.
> **قاعدة ذهبية:** لا تدخل صورة للموقع قبل التحقق من كل كلمة فيها حرفاً حرفاً، خصوصاً **TORRÉFACTION** و **MAROC**.

## 1. الأصول المعتمدة والمدمجة في الموقع

| الملف | ما هو | أين يُستعمل |
|---|---|---|
| `src/assets/brand/label.webp` | **الملصق السداسي المعتمد** (B بحبتي القهوة، الزليج، النصوص الصحيحة)، بخلفية شفافة | قسم «قصة العلامة» + مرجع لكل الصور |
| `src/assets/brand/monogram.svg` | الأيقونة (سداسي + B + حبتان) **بصيغة متجهية SVG**، تأخذ لون النص تلقائياً | رأس الموقع، التذييل، لوحة الإدارة |
| `public/favicon.svg` · `public/apple-touch-icon.png` | أيقونة المتصفح والهاتف | تبويب المتصفح، شاشة الهاتف |
| `src/assets/brand/seal.webp` | ختم Custom Blend الدائري، بخلفية شفافة | الصفحة الرئيسية، ملخص الخلطة الخاصة |
| `src/assets/photos/packshot.webp` | **صورة الكيس الأساسية** 1 كلغ: القالب الفارغ + الملصق المعتمد مركّب فوقه بنفس الإضاءة | كل بطاقات المنتجات وصفحة كل منتج والخلطة الخاصة |

كل الصور مسجّلة في ملف واحد: `src/shared/media.ts` (المقاس الحقيقي لكل صورة حتى لا تتحرك الصفحة أثناء التحميل).
**لتبديل صورة:** ضع الملف الجديد بنفس الاسم، وحدّث العرض والارتفاع في `media.ts`.

## 2. كيف تُصنع صورة كل منتج (بدون جلسة تصوير لكل منتج)

صورة المنتج = **`packshot.webp`** + **ملصق المنتج** يُولَّد مباشرة من بيانات لوحة الإدارة، ويوضع تحت الملصق السداسي:
- اسم المنتج، نسبة أرابيكا/روبوستا، أعلام المصادر، درجة التحميص، الوزن.
- للخلطة الخاصة: «CUSTOM BLEND» + نسب الوصفة، ويتحدّث مباشرة مع كل تغيير.
- **النص دائماً بالفرنسية** مهما كانت لغة الموقع، لأنه نص التغليف الحقيقي.

الكود: `src/shared/ui/ProductVisual.tsx` (الصورة) و `src/shared/sticker.ts` (النص، مع اختبارات).
**منتج جديد يُضاف من الإدارة = صورة صحيحة فوراً.** وإذا صوّرتم منتجاً تصويراً خاصاً، تُعطى صورته في حقل `image` فتحل محل القالب.

## 3. صور مرفوضة: لا تُستعمل أبداً

| الصورة | السبب |
|---|---|
| صورة الكيس الأولى على الخشب المنقوش | خطأ «OUJDA · MARGC» بدل MAROC (أزيلت من المشروع) |
| كل الصور التي فيها **B مزخرف بخط مائل** | شعار غير معتمد، يخلق علامة ثانية |
| الأكياس بحواف ذهبية | لون خارج الهوية |
| الأكياس المكتوب عليها «TORRÉACTION» | حرف F ناقص |
| ملصق Custom Blend الذي تتكرر فيه كلمة RECETTE | خطأ في النص |
| ملصق SIGNATURE بأعلام بلا ألوان | الأعلام غير مقروءة |

## 4. ما زال ناقصاً (الدفعة التالية)

1. **صور مقرّبة لحبوب كل مصدر** (البرازيل، هندوراس، كولومبيا، إثيوبيا، فيتنام، أوغندا) لصفحة أحادي المصدر.
2. **تركيبة الخلطة الخاصة** (كومات حبوب بألوان تحميص مختلفة + ميزان نحاسي) لصفحة الخلطة الخاصة.
3. **الشعار الكامل بصيغة متجهية احترافية** (من مصمّم) لملفات الطباعة. الأيقونة الحالية `monogram.svg` مرسومة آلياً من الصورة المعتمدة: ممتازة للموقع، لكن الطباعة الكبيرة تحتاج رسماً يدوياً دقيقاً.
4. **ملفات طباعة ملصقات المنتجات** (بحجم الطباعة الحقيقي) عند اعتماد القائمة النهائية للمنتجات.

## 5. قواعد طلب صور جديدة من منصات التوليد

1. أرفق دائماً **`label.webp`** كمرجع، واكتب: «استعمل هذا الشعار كما هو دون تغيير».
2. للصور التي ستتكرر: اطلب الكيس **بملصق فارغ لا يحمل إلا B**، ثم يُركّب الملصق المعتمد برمجياً أو بمصمّم.
3. اطلب كل صورة **في ملف منفصل** بأعلى دقة، وليس مجموعة في صورة واحدة.
4. عند التصحيح: اطلب تعديل الصورة الخاطئة فقط، واحفظ الصور المعتمدة فوراً، فكل إعادة توليد قد تُدخل خطأ جديداً.
