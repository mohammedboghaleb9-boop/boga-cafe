# 04 · المواقع والخدمات التي سنستعملها

> الأسعار تتغير. الأرقام هنا تقديرية للتخطيط فقط: **تحقق من صفحة الأسعار الرسمية لكل خدمة قبل الاشتراك.**
> الحسابات تُفتح باسم BOGA CAFÉ وببريد الشركة، وليس بحسابات شخصية، حتى تبقى ملكاً للعلامة.

## 1. الأساسيات (قبل الإطلاق)

| الخدمة | لماذا | متى | التكلفة التقريبية |
|---|---|---|---|
| **GitHub** (github.com) | حفظ الكود وتاريخه، ونشر تلقائي عند كل تعديل | الآن (المستودع موجود) | مجاني |
| **Supabase** (supabase.com) | قاعدة البيانات، تسجيل دخول الإدارة، الصور، وظائف الخادم | المرحلة 2 | مجاني للبداية (المشاريع المجانية تتوقف بعد فترة خمول)، ثم خطة Pro شهرية عند الإطلاق الفعلي |
| **Cloudflare Pages** (cloudflare.com) | استضافة الموقع + حماية + Turnstile ضد السبام | المرحلة 2 | مجاني للاستعمال التجاري **(للتحقق)** |
| بديل: **Vercel** (vercel.com) | استضافة | — | الخطة المجانية لغير التجاري، التجاري يحتاج خطة Pro شهرية **(للتحقق)** |
| **اسم النطاق** `bogacafe.ma` أو `bogacafe.com` | عنوان الموقع | المرحلة 2 | اشتراك سنوي. `.ma` عبر مسجّل معتمد في المغرب **(التحقق من التوفر والشروط)** |

## 2. الدفع

| الخدمة | لماذا | ملاحظات |
|---|---|---|
| **CMI** (Centre Monétique Interbancaire) عبر البنك | الدفع بالبطاقة (Visa, Mastercard, البطاقات المغربية) مع 3-D Secure | يتطلب: شركة مسجلة، حساب بنكي مهني، موقع فيه شروط البيع والخصوصية ووسائل الاتصال. تكاليف: رسوم انضمام و/أو اشتراك + **عمولة على كل عملية** (تُتفاوض مع البنك). الربط: صفحة الدفع الخاصة بـ CMI + رابط callback موقّع |
| بدائل للمقارنة | بوابات دفع مغربية أخرى (Payzone، YouCan Pay…) | قد تكون أسرع في الانضمام. **قارن** العمولات وسرعة التحويل للحساب البنكي قبل الاختيار |
| **Cash Plus** | الدفع نقداً في الوكالات | البداية: **يدوي** (الزبون يرسل المبلغ باسم المستفيد + يرسل الوصل، الإدارة تتحقق). لاحقاً: اسأل Cash Plus عن خدمة التحصيل للتجار (دفع بمرجع) **(للتحقق)** |
| **التحويل البنكي** | للزبائن والمهنيين | يدوي: RIB + رقم الطلب كمرجع، والإدارة تؤكد |

## 3. الإشعارات والتواصل

| الخدمة | لماذا | ملاحظات |
|---|---|---|
| **WhatsApp Business** (تطبيق) | الرد على الزبائن يومياً | رقم خاص بالعلامة |
| **WhatsApp Cloud API** (Meta for Developers + Meta Business) | إرسال رسالة آلية للإدارة عند كل طلب/عيّنة | يحتاج حساب Meta Business موثّق، **رقم مخصص للـ API** (غير مستعمل في تطبيق واتساب العادي)، وقالب رسالة (Utility) موافق عليه. تكلفة صغيرة لكل رسالة حسب تسعيرة Meta للمغرب **(للتحقق)** |
| **CallMeBot** (مُفعّل في `api/notify.ts`) | تنبيه واتساب آلي **لرقم صاحب المشروع** عند كل طلب/عيّنة/طلب B2B | مجاني، تفعيل برسالة واحدة. مناسب لتنبيه الإدارة؛ الترقية لاحقاً: WhatsApp Cloud API. التفاصيل: [`09-notifications.md`](09-notifications.md) |
| **Gmail** | إشعارات بالبريد للإدارة (كما يطلب التقرير) | الإرسال الآلي عبر SMTP بكلمة مرور تطبيق (App Password) بعد تفعيل التحقق بخطوتين. حد يومي للإرسال كافٍ لإشعارات الإدارة |
| لاحقاً: **Google Workspace** + خدمة بريد (Resend أو Brevo) | بريد مهني `contact@bogacafe.ma` وإرسال تأكيدات للزبائن | عند امتلاك النطاق |

## 4. التسويق والقياس

| الخدمة | لماذا |
|---|---|
| **Instagram / TikTok / Facebook** (حسابات أعمال) | الروابط في الموقع، المحتوى، الإعلانات |
| **Meta Business Suite** | إدارة إنستغرام وفيسبوك والإعلانات من مكان واحد |
| **Google Search Console** | الظهور في Google ومتابعة الأخطاء |
| **Google Analytics 4** أو **Plausible** | إحصائيات الزيارات ومعدل التحويل (مهم لقياس أثر «لا دفع عند الاستلام») |
| **Google Business Profile** | الظهور في خرائط Google بوجدة |

> أي أداة تتبع (Pixel، Analytics) تحتاج **موافقة الزائر** (نافذة الكوكيز) احتراماً للقانون 09-08.

## 5. التشغيل

| الخدمة | لماذا |
|---|---|
| **شركة التوصيل**: Amana (بريد المغرب)، CTM Messagerie، أو شركات التوصيل للتجارة الإلكترونية (Sendit، Cathedis، Ozon Express…) | قارن: الأسعار حسب المدينة والوزن، المدة، التأمين، وتوفر API للتتبع. أسعارهم ستحدد جدول «التوصيل» في الإدارة |
| **Sentry** | تنبيه فوري عند أي خطأ في الموقع |
| **UptimeRobot** أو ما يشابهه | تنبيه إذا توقف الموقع |
| **محاسب** | الشكل القانوني، الضريبة، الفواتير |

## 6. ملخص الحسابات التي يجب فتحها (بالترتيب)

1. بريد Gmail للعلامة (إن لم يكن موجوداً).
2. رقم واتساب للأعمال + رقم ثانٍ للإشعارات الآلية (أو نفس الرقم إذا استُعمل عبر API فقط).
3. حساب بنكي مهني + طلب عقد CMI (أطول إجراء، يبدأ مبكراً).
4. Supabase + Cloudflare (أنا أجهّزهما في المرحلة 2 عند موافقتك).
5. Meta Business (للـ WhatsApp Cloud API وإعلانات إنستغرام/فيسبوك).
6. النطاق.
7. Search Console + Analytics عند الإطلاق.
