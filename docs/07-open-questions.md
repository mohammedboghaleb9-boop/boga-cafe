# 07 · أسئلة مفتوحة لصاحب المشروع

لم أتوقف عند هذه الأسئلة: أخذت لكل واحد قراراً افتراضياً معقولاً (العمود الأخير) حتى يعمل النموذج. أجوبتك تغيّر رقماً في الإعدادات أو بياناً، وليس البنية.

## الأسئلة ذات الأولوية (تؤثر على المرحلة 2)

| # | السؤال | الافتراض الحالي |
|---|---|---|
| Q1 | **المخزون بالكيلو: قهوة محمّصة جاهزة، أم قهوة خضراء عند المحمّص؟** | محمّصة. (إن كانت خضراء: نضع نسبة الفقد ~15–18% في الإعدادات) |
| Q2 | **أين تتم عملية الخلط والتعبئة: عند المحمّص أم عند BOGA؟** | يحدد من يستقبل «ورقة الغرامات» لكل طلب، وحالة «قيد الإنتاج» |
| Q3 | **القائمة النهائية للمصادر والخلطات والأسعار** (بما فيها خلطات B2B الثلاث) | بيانات تجريبية واقعية: 6 مصادر، 3 خلطات مميزة، 4 أحادية المصدر، 3 خلطات B2B |
| Q4 | **هل الأسعار المعروضة شاملة للضريبة (TTC)؟** | نعم، أسعار نهائية للزبون |
| Q5 | **الشكل القانوني والبنك** (لطلب CMI) | غير محدد. البطاقة تعمل بمحاكاة، وكاش بلوس والتحويل جاهزان |
