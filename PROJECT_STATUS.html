01نظرة عامة

شنو: موقع ومتجر لعلامة قهوة الحبوب BOGA CAFÉ (وجدة). منتجات Signature وأحادية المصدر وB2B، وCustom Blend كيركّبو الزبون.

الهدف: بيع مباشر بالدفع قبل التحضير (Cash Plus، تحويل، البطاقة من بعد)، وطلبات B2B فوق 10 كلغ.

اللغات: العربية (RTL)، الفرنسية، الإنجليزية. الإدارة: owner / manager / staff مع 2FA.

التقنية: React 19 + Vite 8، Supabase (PostgreSQL 17.11 + RLS + Edge Functions)، Cloudflare Workers.

القنوات: WhatsApp، Gmail، Instagram، TikTok، Facebook (حقيقية، src/data/contact.ts).

القاعدة الذهبية: قاعدة البيانات كتعاود تحسب كل طلب وما كتثيقش فالمتصفح.
